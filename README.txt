HOJA DE VIDA WEB - FRANK ANGEL GIRALDO

1. Abre esta carpeta en Visual Studio Code.
2. Guarda tu fotografía como:
   img/foto.jpg
3. Abre index.html con Live Server.
4. Revisa la hoja de vida.
5. Pulsa "Descarga en pdf".

El diseño sigue la estructura de la guía: Bootstrap 5, Font Awesome,
HTML5, CSS propio y JavaScript para exportar a PDF.

NOTA:
La guía utiliza una fotografía en la carpeta img. Como no se adjuntó
una foto tuya, debes colocar tu propia foto con el nombre foto.jpg
para que aparezca en el mismo lugar del diseño.
